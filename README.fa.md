# Kudos to Open Source

[English](README.md) · [فارسی](README.fa.md)

> **برای نرم‌افزارهایی که بابتشان پول می‌دهید، جایگزین متن‌باز پیدا کنید.**

این مخزن یک فهرست community-maintained از جایگزین‌های متن‌باز نرم‌افزارهای تجاری است؛ با اطلاعات کاربردی درباره‌ی **سیستم‌عامل/پلتفرم قابل اجرا، لینک نصب یا نحوه استفاده و محدودیت‌های مهم هر پروژه**.

## وب‌سایت

وب‌سایت استاتیک GitHub Pages پروژه شامل این قابلیت‌هاست:

- جست‌وجوی سریع بر اساس نام نرم‌افزار تجاری یا پروژه متن‌باز؛
- تغییر زبان **فارسی / انگلیسی** با پشتیبانی کامل RTL/LTR؛
- دسته‌های دقیق مثل **ویرایش ویدئو، پخش‌کننده ویدئو، ویرایش تصویر، IDE و ویرایشگر کد، LLM، API Client، CAD، GIS و مدیریت رمز عبور**؛
- فیلتر بر اساس **پلتفرم**، دسته‌بندی، مدل انتشار و میزان شباهت؛
- لینک مستقیم **نصب / نحوه استفاده** برای هر پروژه؛
- نمایش پلتفرم‌هایی مثل Windows، macOS، Linux، Android، iOS، Web، Docker، CLI، VS Code و JetBrains؛
- برچسب‌های کوتاه **نکات و محدودیت‌ها** برای هر پروژه؛
- URL قابل اشتراک برای جست‌وجو و فیلترها، طراحی responsive و پوسته روشن/تیره.

اجرای محلی:

```bash
python scripts/validate.py
python scripts/build_site.py
python -m http.server 8000 --directory dist
```

سپس `http://localhost:8000` را باز کنید.

## ساختار داده

اطلاعات هر پروژه فقط یک بار در `data/projects.yml` تعریف می‌شود؛ بنابراین اگر یک پروژه جایگزین چند محصول باشد، لینک نصب، پلتفرم و محدودیت‌ها تکراری نمی‌شوند.

```text
data/
├── alternatives.yml       # mappingها
├── projects.yml           # اطلاعات پروژه و نصب/پلتفرم/محدودیت
├── categories.json        # شناسه دسته‌ها
├── locales.json           # زبان‌های فعال
└── locales/
    ├── en.json
    └── fa.json
```

برای اضافه‌کردن زبان سوم لازم نیست frontend تغییر کند. راهنما را در [docs/i18n.md](docs/i18n.md) ببینید.

## مشارکت

اضافه‌کردن پروژه، اصلاح لینک نصب، تصحیح پلتفرم‌ها، بهبود ترجمه یا limitation tagها و اصلاح لایسنس‌ها همگی welcome هستند. قبل از Pull Request فایل [CONTRIBUTING.md](CONTRIBUTING.md) را بخوانید.

CI بررسی می‌کند که هیچ پروژه‌ای بدون لینک نصب/استفاده، پلتفرم، limitation و ترجمه باقی نمانده باشد.
