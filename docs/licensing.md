# Licensing notes

License information changes. Always treat the upstream repository's current license files as authoritative.

The `license` field in this catalog is a discovery aid, not legal advice.

## Mixed repositories

Some repositories combine open-source and proprietary code. Those entries should be labeled `open-core` and their license field should make the mixed nature visible, for example:

```text
AGPL-3.0 / mixed
MIT / mixed
```

## Trademarks

Open-source licensing does not automatically grant trademark rights. Project names and logos may have separate trademark policies.

## Recommended review

For important production or redistribution decisions, inspect the exact upstream version you intend to use and, where necessary, obtain legal advice.
